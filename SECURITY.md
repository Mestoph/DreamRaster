# Security / Sécurité

## Français

Ne publiez pas de vulnérabilité exploitable avec des données privées dans une issue publique. Utilisez les moyens de contact privés du propriétaire du dépôt lorsqu'ils sont disponibles.

## English

Do not publish exploitable vulnerabilities together with private data in a public issue. Use the repository owner's private contact channel when one is available.
